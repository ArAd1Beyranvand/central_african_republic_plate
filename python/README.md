# central_african_republic_plate

Central African Republic's licence plates for the plate_core library: the black-on-white CEMAC plate, a theme, alphabets and an advisory validator.

## Quick start

### Install (Python)

Copy `python/plates/countries/central_african_republic/` into `plate_core/python/plates/countries/`.

Then run the tests from `plate_core/python/`: `pytest`.

### Use

```python
from plates.countries.central_african_republic.data import SPECS, THEMES

spec = SPECS["cf.private"]
theme = THEMES["CentralAfricanRepublicThemes.private"]
print(spec.id)
```

## Specs

The specs are the same in every language (they come from shared data).

- `cf.private`

## Themes

- `CentralAfricanRepublicThemes.private`

## Change it

- Pick a spec: use another key of `SPECS`.
- Pick a theme: use another key of `THEMES`.
- Validators: `VALIDATORS` maps the names `CentralAfricanRepublicValidator` to classes.
