# central_african_republic_plate

Central African Republic's licence plates for the plate_core library: the black-on-white CEMAC plate, a theme, alphabets and an advisory validator.

## Quick start

### Install (TypeScript)

Copy `typescript/src/countries/central_african_republic/` into `plate_core/typescript/src/countries/`.

Then run the tests from `plate_core/typescript/`: `npm test`.

### Use

```ts
import country from './countries/central_african_republic';

const spec = country.specs.get('cf.private');
console.log(country.package);
```

## Specs

The specs are the same in every language (they come from shared data).

- `cf.private`

## Themes

- `CentralAfricanRepublicThemes.private`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`CentralAfricanRepublicValidator`).
